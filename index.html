NucleoSense provides real-time monitoring and control of STM32-based medical device sensors with full 21 CFR Part 11 compliance including tamper-evident audit trails, electronic signatures, role-based access control, and password policy enforcement.
Compliance Features
Electronic Signatures (§11.50) — Re-authentication on every critical change
Tamper-Evident Audit Trail (§11.10e) — Append-only with checksums
Role-Based Access Control (§11.10d) — Administrator, QA, Operator roles
Password Policy (§11.300) — Complexity, expiry 90d, history 5, lockout 3
Session Timeout (§11.300d) — 30 min inactivity with countdown warning
Reason for Change (§11.10a) — Mandatory on all setpoint changes
Record Integrity (§11.10c) — Setpoint history append-only, never deleted
System Event Logging (§11.10e) — Boot, shutdown, all events logged
21 CFR §11.10(d) — System access controls. Each role has strictly defined privileges.
